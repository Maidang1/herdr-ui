# M3 标签、分屏与输入实施计划

目标：按主文档 §5/§7 实现当前标签的真实分屏、多实例差量、右分/下分、方向聚焦、zoom、比例调整和业务 prefix；保留 M0/M1/M2 回归，不增加创建标签或工作树入口。

- [x] 保留权威布局矩形与 zoom，纯计算投影、split 命中/路径、忽略比例的结构指纹。
- [x] 扩展闭合操作：Neighbor / Split / Zoom / ExportLayout / SetRatio；显式目标、串行请求、重复 split 拦截、比例最新槽、未知结果不重放。
- [x] App 动作与 pending intent：捕获目标、epoch、ViewRevision，完整快照确认后选择新 pane；迟到结果不抢焦点。
- [x] 多 pane 原生容器、局部标题、聚焦、标签恢复、zoom 差量释放/重建、拖动/resize 预览与最终比例。
- [x] 绑定来源、prefix/字面转义、取消/resize/组字边界和菜单共享动作；不能支持的有效配置明确诊断，不伪称服务端生效键位。
- [x] 契约/竞态/真实服务与窗口自动回归、独立审查、验收记录、打包和本地提交；系统交互人工验收单独保留。

M0 未通过的系统 IME 与真实鼠标等验收继续如实记录；插件能力不足时先核查公开能力与最小修复路径。

实现与自动验证证据见 [m3-validation.md](m3-validation.md)。完成以上实现不代表 M0/M3 系统 IME、鼠标与输入隔离人工验收已通过。
