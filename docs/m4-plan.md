# M4 原生收尾实施计划

依据：主文档 §2、§7、§9、§10。沿用既定设计与用户持续执行授权。

**目标：**完成原生参考面板、紧凑头部与标签菜单、可调整侧栏、外观/焦点/辅助名称，保留 M3 布局与输入边界。

**架构：**Window 管理本地 UI 状态，参考面板与终端并排；尺寸规则用纯计算保持 344px 面板与至少 400px 终端，窄窗口临时隐藏侧栏而不修改用户侧栏偏好。原生 mygo 公开 API 提供系统外观、材质与无障碍偏好；不重写插件或访问私有终端视图。

- [x] UI：增加右侧参考面板、侧栏底部键盘入口；关闭恢复终端焦点，Esc 仅在面板焦点范围生效。
- [x] UI：40px 单行头部、columns-2 布局入口、标签菜单（数量/勾选/完整名称），移除 M3 常驻第二行按钮；prefix/resize 临时提示保留。
- [x] UI：侧栏220–320拖动与紧凑布局规则，820×560/1200×800亮暗回归与截图检查；避免重复 M3 帧内布局来源问题。
- [x] 原生外观：材质、0.96渐变、减少透明度fallback、增加对比度、失焦选中状态；沿用系统字体和原生菜单。
- [x] 辅助功能与验证：控件辅助名称、焦点指示、Esc范围、菜单启用、输出与快速切换/退出回归。
- [x] 独立规格与质量审查，完整竞态/vet/隔离真实集成、打包签名，文档与本地提交。

系统 IME、真实鼠标、VoiceOver 和系统偏好切换的实机验收继续独立记录，不能用 headless 测试替代。阶段证据写入 docs/m4-validation.md。

完成情况与明确未验收的系统交互见 [M4 验收记录](m4-validation.md)。
