# Application icon sources

Lucide and Lobe icons are generated from the exact versions in package-lock.json. SOURCES.txt records every original file and display mode. Lucide SVGs retain their ISC license and the applicable Feather-derived MIT notice in LICENSE-lucide. Lobe SVGs retain the upstream MIT license in LICENSE-lobe; its original source is vendored at assets/licenses/lobe-icons-1.98.0.LICENSE, downloaded from upstream commit 86b3f06ad9a4cc57011a56e5a7d3a5d4f1e8d835.

Agent marks for Claude Code, Codex, Gemini CLI, OpenCode, GitHub Copilot, Cursor, and Kimi are the color SVGs in assets/agent-logos. The generator copies them unchanged. The interface draws them with ui.Image so their fills stay. In a dark window, pure black ink in those files is drawn white; every other color stays. The GitHub repository mark remains the monochrome Lobe icon and is rendered through ui.Icon. Existing assets/icons remain design sources with their separate NOTICE.md; they are not mislabeled as generated Lucide resources.
